# Backup and recovery

**Your data is only in this browser.** Clearing site data, using private browsing, or removing the installed app deletes it. The app requests persistent storage, but browsers may still evict data.

- **Full backup:** More → Backup → *Download full backup*. This includes characters, history, level snapshots, campaigns, encounters, custom content and settings, with a SHA-256 integrity digest.
- **Restore or merge:** shows an import report (counts, integrity result, invalid records, warnings) and lets you choose how duplicates are handled: keep both, replace, or skip. Nothing existing is deleted.
- **Replace everything:** clears the library and restores the backup in **one transaction**. If anything fails, nothing changes. Explicit confirmation is required.
- **Single character:** Export character (JSON) includes its history, snapshots and the custom content it depends on.
- **Text summary / print:** human-readable copies for your DM or a paper backup.

Recommended practice: back up after every session, and keep backups in cloud storage you control.
